## 📦 Install Hub

From the repo (maintainers) or pub (consumers):

```bash
just install && just global    # repo: pub get + path-activate packages/oka
# or: dart pub global activate oka

dart pub global activate oka   # consumer install (Dart 3.14+)
oka get android-sdk            # bootstrap ~/.oka/android-sdk
oka doctor                     # toolchain + device readiness
```

Verified: `packages/oka/bin/oka.dart` (`get`, `doctor`), `justfile` recipes.

## 🏗️ Init Station

```bash
oka init                       # scaffold tool/oka_pipeline.dart (typed config)
oka init --yaml                # legacy oka.yaml + Gradle porting checklist
oka init --from-yaml           # convert existing oka.yaml → Dart entrypoint
oka explain                    # validated plan, no tools run
oka explain --targets          # project-declared targets + step chains
```

Gradle porting (after `oka init --yaml` checklist — why: [DESIGN_FAQ](DESIGN_FAQ#gradle-conversion)):

```bash
oka explain                      # validate plan before build
oka build apk                    # missing classes → dependency suggestion output
```

Verified: `InitCommand`, `ExplainCommand`; flags match `oka init --help`;
`suggestion` path in `packages/oka_android/lib/src/build/dependency_suggest.dart`.

## 🔨 Build Bench

```bash
oka build apk                  # debug APK (no-Gradle pipeline)
oka build apk --release
oka build aab                  # Play upload format
oka compare old.apk new.apk    # byte-equivalence gate (exit 1 on diff)
oka explain --deps             # dependency plan (offline cache)
oka explain --deps --network   # full resolution
```

Verified: `BuildCommand`, `CompareCommand`, `ExplainCommand` usage text in
`packages/oka/bin/oka.dart`.

## 📱 Run & Dev Loop

```bash
oka run device                 # install → launch → failure-signature scan
oka launch                     # alias of oka run device
oka dev                        # converged session (oka run dev)
oka dev android                # Flutter attach + optional --json control
oka dev android --watch        # Dart saves → reload; native → honest rebuild path
```

Verified: `dev_command.dart`, `run_command.dart`; `oka dev android --help`
(ADR-0011).

## 🎯 Target Station

Targets compile from `tool/oka_pipeline.dart`—discovered, not hard-coded in core:

```bash
oka run                        # list declared targets when argv empty
oka run verify                 # release startup ladder (ADR-0029)
oka explain --targets
```

Verified: `dispatchUnknownVerb` / `RunCommand` (ADR-0015); example
`VerifyTarget` in project pipelines.

## 🩺 Plan & Debug Desk

```bash
oka why <step-cache-name>      # step-cache staleness (e.g. release-aot)
oka debug step <step-name>     # single pipeline step probe
oka debug dex <apk> --find <class>
oka doctor
```

Verified: `WhyCommand`, `DebugCommand`, `DoctorCommand` in `oka.dart` usage.

## 🔬 Live & ship (checkout)

Need `oka_dart_kernel` in the workspace for full surface:

```bash

oka live --help                # agent verbs; orchestration in oka_update
```

Verified: `ship_command.dart`, `live_command.dart` registration in `oka.dart`.
