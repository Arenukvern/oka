# Docs map

Oka's documentation is layered: behavior SSOT is code + tests; docs link,
never paraphrase implementation.

| Layer | File(s) | Answers |
|---|---|---|
| Charter | [why_this_repo_matters](why_this_repo_matters) | What oka owns, invariants, success criteria |
| How-to | [`docs/guides/build_and_config.mdx`](../guides/build_and_config) | Run, build, test, configure, troubleshoot |
| Distribution | [`docs/guides/accounts_and_stores.mdx`](../guides/accounts_and_stores) + [`publishing.mdx`](../guides/publishing) | Stores, developer accounts, white-label variants, credentials |
| Web | [`docs/guides/web_shell_station.mdx`](../guides/web_shell_station) | Web shell composition, store contributions, deploy targets |

| Status | [`docs/PHASE_CHECKLIST.mdx`](../PHASE_CHECKLIST) | Phase plan + test evidence map |
