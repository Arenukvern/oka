# Declarative resource composition (ADR-0026)

**Status:** shipped. The reusable composition contract this plan proposed
is a package: `packages/resource_composition` — v0.8.0 on pub.dev, a
zero-dependency, vendor-neutral contract (consumers must not import
oka). It is consumed by the `oka_supervisor` planner/converge/codec, the
`oka_core` leased-process seam (`LeasedProcessProvider`), and the oka
CLI `supervisor` command; the first cross-project adapters landed
2026-09-27 (R0 evidence:
[process-lifecycle R0 survey](../evidence/process-lifecycle-r0-survey-2026-09-27)).

## Where to look

- `packages/resource_composition/README.md` — the contract: component
  graphs validated before side effects, readiness dialects, typed
  output promises, lifecycle events with terminal causes, provider seam.
- [Supervisor guide](supervisor) — the largest consumer: declaring
  desired state over the composition substrate
  (`oka supervisor status|apply|check`).
- [Capability architecture](capability_architecture) — the boundary and
  lifecycle-ownership rules the contract and its adapters follow.
- [ADR-0026](../decisions/0026-declarative-resource-composition-sdk) —
  the design decision this plan executed.
