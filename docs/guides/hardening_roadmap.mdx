# Build hardening roadmap (delivered)

Complications surfaced by the first production e2e (`last_answer`, Sep 2026),
each classified **SDK** (typed API surface), **CHECK** (doctor / dry-run /
post-build lint), or **AUTO** (oka resolves without config). All items below
have landed — this page is the historical record; current behavior is
documented in the [build & configuration guide](build_and_config).

## What shipped

- **SDK**: `MavenResolver` (POM graph walker: parent chain, BOM imports,
  dependencyManagement, properties; parallel BFS; per-artifact failure
  isolation), `MavenRepoRegistry` (declarative group-prefix → host map,
  user-extensible), single `MavenCoordinate` in `oka_core`,
  `ProcessRunner`/`SystemProcessRunner` (injectable, timeouts), typed
  `PipelineEvent`s on `Pipeline.run(..., onEvent:)`, gradle parser corpus
  under `test/fixtures/gradle/` with conditional-block flagging.
- **Checks**: `oka explain` (full plan, zero tool invocations),
  `oka explain --deps` ([ADR-0008](../decisions/0008-dependency-plan-dry-run)),
  `PostBuildLintStep` (version fields present, debug-signed release fails
  unless `--allow-debug-signing`, size budget, bundletool version byte
  check, duplicate-class pre-warning), `oka doctor` additions (kotlin/
  bundletool/JDK, repo reachability, package_config staleness, Maven cache).
- **Auto-resolve** (ADR-0007 policy — automatic with loud notices; escapes
  are env/flag, never new YAML fields): dev-only plugin exclusion, version
  fallback from pubspec, java_version bump to detected max, missing
  kotlinc/bundletool auto-install (`OKA_NO_AUTO_INSTALL=1` escapes), stale
  package_config silent `flutter pub get`, resolver fallbacks.

## Meta-learnings (durable)

- Source-contract tests broke on every file move → prefer API assertions;
  keep path-contract tests in one place.
- Probe-ability (running a single step against a scratch dir) turned
  10-minute loops into 30-second ones → `oka debug step <name>` formalizes
  it.
- Refactor claims should be checkable → `oka compare <apk1> <apk2>` backs
  the byte-equivalence gate.
- A failing host app graph (broken sibling checkouts) must be reported as
  "unresolved in *your* dependency", not as raw kernel output.
