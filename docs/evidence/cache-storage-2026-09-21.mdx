  was performed.

## Scope and limits

Discovery is host-dependent. Android fixtures cover SDK images and custom AVD
paths; Apple fixtures cover device IDs and runtime entries; web fixtures prove
profile preservation. Apple device names are not decoded from plist metadata.
Stats reports logical bytes, not allocated blocks, and does not infer running
device status from directories. Prune scans only eligible scopes, retaining the
full location inventory for protection checks. Age means modification time for
prune and creation time for legacy GC, never last use. Shared prune units are
whole discovered categories; SDK, virtual-device and external-cache cleanup is
left to their owning tools.
