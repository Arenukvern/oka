# Oka — one typed Dart surface to build, run, patch, and distribute apps

![Oka banner](./images/oka-banner.svg)

Oka is a declarative application platform. Its build pillar replaces Gradle
for Flutter Android: it runs `flutter assemble` and invokes Android SDK
tools (`aapt2`, `javac`, `d8`, `zipalign`, `apksigner`) directly — no
Gradle daemon, no AGP, no 30-second configuration tax on every build. The
same laws carry the other pillars: live patching for running programs, a
declarative supervisor for processes, and a content-addressed artifact
store.

The whole config is **one typed Dart file you own** (`tool/oka_pipeline.dart`)
— stores, developer accounts, branded variants, and publish targets are
just more values in it.

![Build pipeline (no Gradle)](./images/pipeline-flow.svg)

## The four pillars

| Pillar | What it does | Maturity |
| --- | --- | --- |
| **Build** | No-Gradle APK/AAB, provenance, byte-equivalence gates | Production (pub.dev, 0.8.0) |
| **Distribute** | Play / AppGallery / RuStore / web stores, multi-account, white-label — dry-run by default | Production (pub.dev) |
| **Update** | Live per-unit patching of running programs; `oka run dev`, `oka ship` air channel | Gate-proven experimental (checkout) |
| **Operate** | Supervisor, process leases, session-state, artifact store with delta chains | Production at ladder rung L0 |

## Highlights

- **No Gradle, ever** — the default path never falls back to
  `flutter build apk` (enforced by tests).
- **Explain before execute** — `oka explain` shows the validated plan; zero
  tools run.
- **Stores & accounts as values** — Play, AppGallery, RuStore, web deploy
  targets; dry-run by default; per-account credentials by path.
- **Live updates that work** — per-unit patching of running programs,
  gate-proven on macOS/Android/web and three real products; `oka ship`
  publishes signed store-free channels.
- **Declarative operations** — supervisor plans converge once, process
  leases make every spawned emulator/browser stoppable, artifacts stay out
  of git behind content-addressed pointers.
- **Plugin packaging** — Flutter plugin sources, Maven/AAR dependencies
  (natives + resources included), `GeneratedPluginRegistrant`.
- **Fast settings** — extra deps (`extra_deps`), extra assets, deeplinks,
  adaptive vector launcher icons: all declarative.
- **Dependency recovery** — runtime missing-class crashes map back to Maven
  artifacts automatically.

```bash
dart pub global activate oka     # or from the repo: just global
oka get android-sdk && oka doctor
cd example && oka build apk
```
