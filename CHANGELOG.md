# Changelog

Release history for the **oka** CLI and workspace packages is maintained in
[`packages/oka/CHANGELOG.md`](packages/oka/CHANGELOG.md).

Versions on `main` are bumped via [release-please](https://github.com/googleapis/release-please)
when conventional commits land. Other packages in `packages/` may have their own
`CHANGELOG.md` files synced from the same release train.
